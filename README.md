# frameforward.no

Nettsiden til Frame Forward AS, hostet gratis på GitHub Pages.

- Sidene lages av `tools/build.py` (tekst, kontaktinfo og resultater står der). Kjør `python3 tools/build.py` etter endringer.
- Design: `style.css`. Bilder i `img/`, videoer i `video/`, fonter (selvhostet, SIL OFL / Apache) i `fonts/`.
- Domenet styres av filen `CNAME`.
